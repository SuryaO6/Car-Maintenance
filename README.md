# 🚗 Car Maintenance

A simple and lightweight application to track vehicle maintenance, fuel logs, and service schedules.

---

## ✨ Features

- **Service Tracking:** Log oil changes, repairs, and part replacements.
- **Fuel Log:** Track gas refills and calculate average mileage.
- **Reminders:** Keep track of upcoming maintenance dates and costs.

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js / Express
- **Database:** MongoDB
